# core-java-banking-ms
A Core Java Banking Management System project demonstrating OOP concepts such as Encapsulation, Constructors, and Methods. Includes account management, deposits, withdrawals, and balance enquiry features.
# Banking Management System

A console-based Banking Management System developed using Core Java 21 and Object-Oriented Programming.

## Technologies Used
- Java 21
- IntelliJ IDEA

## Features
- Account creation
- Deposit money
- Withdraw money
- Check account balance

## Project Structure
```text
src/
├── Main.java
├── model/
│   └── Account.java
├── service/
│   └── BankingService.java
└── exception/
    └── AccountNotFoundException.java
```

## Concepts Used
- Encapsulation
- Classes and Objects
- Constructors
- Methods
- Conditional Statements
