# Banking Management System

A Core Java project designed to simulate basic banking operations using Object-Oriented Programming (OOP) concepts.

## Project Overview

The Banking Management System helps manage bank accounts and perform basic banking transactions.

## Technologies Used

- Java 21
- IntelliJ IDEA
- Git & GitHub

## OOP Concepts

- Encapsulation
- Classes and Objects
- Constructors
- Methods
- Access Modifiers

## Project Structure

```text
BankingManagementSystem/
└── src/
    ├── model/
    │   └── Account.java
    ├── service/
    │   └── BankingService.java
    ├── exception/
    │   └── AccountNotFoundException.java
    └── Main.java
```

## Features

- Account Management
- Deposit Money
- Withdraw Money
- Check Account Balance

## Learning Goals

- Understand Core Java concepts.

- Implement real-world banking operations.
- Improve Java problem-solving skills.
